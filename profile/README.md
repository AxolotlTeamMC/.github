## Welcome to AxolotlTeamMC 👋

**AxolotlTeamMC** is an independent development studio focused on building high-performance software, robust infrastructure, and innovative tools for the Minecraft ecosystem. Our mission is to deliver reliable, modern, and production-ready solutions for both players and developers.

### 🛠️ Our Core Projects
* **Custom Minecraft Launcher:** A sleek, feature-rich, and secure desktop launcher designed for seamless modpack management, fast loading times, and an enhanced user experience.
* **AxolotlPackets:** A high-performance, strictly-typed implementation of the Minecraft network protocol built from scratch for next-gen server architecture.
* **Server Infrastructure:** Scalable core modules and backend utilities optimized for heavy workloads and custom server deployments.

### 💻 Technology Stack
We select our technologies with a focus on speed, safety, and modern user experiences:
* **Backend & Systems:** `Rust` (for high-performance networking and core utilities), `Java` (for native Minecraft integration and backend services).
* **Frontend & UI:** `Angular` / `TypeScript` (for building fast, responsive, and clean user interfaces for our desktop and web apps).

### 🌈 Contribution & Collaboration
We heavily support the open-source community. If you are interested in contributing to our launcher, core protocol libraries, or toolsets, feel free to explore our repositories, open issues, or submit pull requests. Let's push the boundaries of Minecraft development together.
